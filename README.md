Customer Churn Prediction Using Machine Learning

Project Overview

Customer Churn Prediction is a Machine Learning project that predicts whether a customer is likely to leave a company's services.

Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Streamlit

Project Features

- Customer information input
- Churn prediction
- Machine Learning model integration
- Prediction history
- Interactive user interface

Project Files

- "app.py" – Streamlit application
- "churn_prediction.py" – Prediction logic
- "churn_model.pkl" – Trained ML model
- "scaler.pkl" – Data scaler
- "requirements.txt" – Required libraries
- "prediction_history.csv" – Prediction history
- "WA_Fn-UseC_-Telco-Customer-Churn.csv" – Dataset

How to Run

1. Install the required packages:
   
   "pip install -r requirements.txt"

2. Run the application:
   
   "streamlit run app.py"

Project Objective

To help businesses identify customers who may leave their services and support better customer retention strategies.
